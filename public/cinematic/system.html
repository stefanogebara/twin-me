00

Principles

The system exists to make a personal AI feel like it has a soul — not a dashboard.
Photography is the surface

Real Figma photographs carry every screen. Never flat night-sky fills — depth, personality, life. UI floats over the image in glass.

Zoned, always legible

Photos are vivid where the eye lands (greeting / hero) and fade to near-black where you work. Text never fights the image.

Serif soul, sans spine

Instrument Serif speaks; Roboto Serif narrates; Inter runs the machine. The mix is the voice.

Glass, not chrome

One material — liquid glass with true refraction — for every panel, chip and bar. Quiet, tactile, consistent.

04

Liquid glass

Anatomy follows Apple's Liquid Glass: lensing at the edges, a specular rim lit from above, adaptive luminosity, shadow that implies thickness.

.glass — regular

Blurs and adjusts the luminosity of what's behind it so text stays legible. Specular rim instead of a flat border. For panels, bars, cards.

.glass.refract — lensed

Adds edge lensing: the center stays calm, the rim bends the backdrop outward like a real lens. Reserve for a few hero elements.

.glass--clear

Highly translucent, for controls floating over photos and video. Add a 35% black dim layer when the media behind is bright.

/* anatomy (after Apple's Liquid Glass — HIG Materials, WWDC25 "Meet Liquid Glass") 1 fill warm tint · backdrop luminosity adjusted, not just blurred 2 specular gradient rim, lit from above (replaces the flat 1px border) 3 shadow contact + deep ambient — bigger glass reads thicker 4 lensing EDGE displacement only (calm center) — never noise */ .glass { background: linear-gradient(160deg, rgba(42,34,48,.60), rgba(22,19,28,.72)); border: 1px solid rgba(255,255,255,.07); border-radius: 16px; backdrop-filter: blur(42px) saturate(1.4) brightness(.94); box-shadow: 0 1px 2px rgba(0,0,0,.18), 0 12px 32px rgba(0,0,0,.26), inset 0 0 34px rgba(255,255,255,.02); } .glass::after { /* specular rim */ inset:0; padding:1px; border-radius:inherit; background: linear-gradient(180deg, rgba(255,255,255,.36), rgba(255,255,255,.07) 26%, rgba(255,255,255,.02) 62%, rgba(255,255,255,.20)); mask: linear-gradient(#fff 0 0) content-box, linear-gradient(#fff 0 0); mask-composite: exclude; } .glass.refract { backdrop-filter: blur(42px) saturate(1.4) brightness(.94) url(#liquid); } /* Rules (per Apple HIG): use sparingly — glass is the floating functional layer, not the content layer; never stack glass on glass; nested corners stay CONCENTRIC (inner radius = outer radius − inset). */ /* TWO APPEARANCES — the user chooses (◐ toggle, persisted) dark night photography · warm-tinted glass · bone primary light DAYLIGHT photography (soul-waves, chair-hill, meadow, golden field) · translucent white glass with a brightness lift, not opacity · gentle paper veils — the photo must breathe through · primary flips to ink · sidebar frosts (regular-variant glass) theme-aware imagery: swaps automatically; CSS backgrounds override per page under [data-theme="light"]. Exception: immersive pre-auth screens (onboarding, interview) stay dark. */

07

Motion

Slow, breathing, cinematic. Nothing snaps.
Reveal on scroll

Content rises 16px + fades in over 0.7s as its band enters the viewport. Above-the-fold reveals instantly; reduced-motion shows everything static.

Breathe

The hero light-beam pulses opacity 0.75→1 over 7s — a slow inhale behind the wordmark.

Easing

cubic-bezier(.4,0,.2,1) everywhere. Buttons lift 2px on hover with a soft shadow.
